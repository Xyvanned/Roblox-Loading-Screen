# ProfileStore goes here

This project depends on **ProfileStore** by loleris (MAD STUDIO), which is not
bundled in this repository.

1. Download `ProfileStore.luau` from
   <https://github.com/MadStudioRoblox/ProfileStore>
2. Put it in this folder so the path is
   `ServerScriptService/Mechanism/DataRelated/ProfileStore` (a ModuleScript).

`PlayerData.luau` requires it with `script.Parent:WaitForChild("ProfileStore")`.
